# Platen frontend

SvelteKit 2, Svelte 5, and TypeScript, built with the Node adapter.

The UI is being rebuilt. Only the homepage remains, displaying catalog Artists
alphabetically. The old artist, album, import, and download screens have been
removed. The shadcn-svelte setup will follow in a separate change.

## Development

Run from this directory:

```sh
npm ci
npm run dev
```

The frontend requests `/api` by default. The Vite development proxy forwards those
requests to `http://localhost:3000`. Set `PLATEN_DEV_BACKEND_ADDRESS` to use another
backend address, or `PUBLIC_PLATEN_BACKEND_URL` to request the backend directly.

## Verification

```sh
npm run check
npm test
npm run build
```

## Production

After building, run:

```sh
node build
```

Route `/api` to the backend through your reverse proxy, or set
`PUBLIC_PLATEN_BACKEND_URL` to the backend's URL. Direct cross-origin requests
require the backend to allow the frontend's origin through CORS.

The types in `src/lib/dto` are generated by the backend. Regenerate them with
`platen-backend/scripts/generate-types.sh` from the repository root.
